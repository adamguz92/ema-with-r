# Źródło danych

https://www.coingecko.com/en/coins/ethereum/historical_data

# Opis danych

Dane zawierają cztery kolumny:
- event_date
- close_price_usd
- market_cap_usd
- volume_usd

W kolumnie o nazwie close_price_usd znajdują sie ceny zamknięcia ETH/USD.

Dane maja interwał dzienny.

Zakres czasowy danych: 07.08.2015 - 19.09.2026.
